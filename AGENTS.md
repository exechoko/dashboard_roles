# Instrucciones del repositorio para Codex

- Seguí `CLAUDE.md` para el contexto de Laravel, las convenciones del proyecto y las reglas de trabajo compartidas con Claude Code.
- Las skills del proyecto están en `.agents/skills/<nombre>/SKILL.md`. Antes de una tarea que coincida con la descripción de una skill, leé sus instrucciones y los recursos que indique.
- Mantené cada skill autocontenida en su directorio, con referencias, scripts y recursos junto a su `SKILL.md`.
