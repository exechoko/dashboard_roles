# Incidencias 911 y tickets PG

## Crear un período de análisis 911

1. Abrí [Períodos 911](/incidencias/periodos).
2. Pulsá **Nuevo período**.
3. Ingresá un número de período único.
4. Definí fecha inicial y final.
5. Completá totales de unidades por sistema y referencias administrativas autorizadas.
6. Guardá.

El sistema calcula automáticamente duración total en días y minutos.

## Agregar una incidencia

1. Abrí el detalle del período.
2. Pulsá **Agregar incidencia**.
3. Elegí tipo, origen, prioridad, sistema y módulo.
4. Completá unidades afectadas y minutos.
5. Revisá ponderaciones y valores calculados.
6. Guardá.

Las incidencias deben pertenecer al período abierto. La opción **Arrastrar persistentes** copia incidencias aplicables del período anterior evitando códigos duplicados.

## Importar incidencias

1. Abrí el período y seleccioná **Importar Excel**.
2. Cargá un archivo XLSX, XLSM o XLS.
3. Elegí el tipo de hoja.
4. Indicá si deben limpiarse datos anteriores, revisando antes el alcance de esa opción.
5. Importá y revisá registros agregados u omitidos.

## Generar informe

1. Abrí el detalle del período.
2. Verificá incidencias, exclusiones, ponderaciones y resultado global.
3. Pulsá la opción de informe autorizada.
4. Descargá y revisá el documento generado.

## Crear un ticket PG

1. Abrí [Tickets PG](/incidencias/tickets-pg).
2. Pulsá **Nuevo Ticket PG**.
3. Indicá origen, categoría, problema, prioridad y subsistema.
4. Asociá cámara, móvil, equipo u oficina cuando la categoría lo solicite.
5. Completá fechas, período y aplicación de multa si corresponde.
6. Revisá asunto y texto sugeridos.
7. Guardá como borrador.

## Enviar un ticket

Disponible con permiso `enviar-ticket-pg`.

1. Abrí el detalle del borrador.
2. Revisá todos los datos y la redacción.
3. Usá la mejora de redacción solo si está habilitada y luego volvé a verificar el texto.
4. Pulsá **Enviar a ticketera**.
5. Confirmá.
6. Revisá el código y estado resultantes.

Un ticket enviado no debe reenviarse ni editarse como borrador. Las respuestas posteriores pueden sincronizarse desde el detalle.
