# Ayuda de C.A.R. 911

Esta base contiene procedimientos funcionales para usuarios autenticados. La disponibilidad de cada módulo y botón depende de los permisos asignados al usuario.

El asistente puede:

- explicar dónde está una función;
- detallar pasos de carga, consulta o actualización;
- orientar sobre filtros, históricos, documentos y estados;
- ofrecer enlaces a pantallas internas habilitadas.

El asistente no ejecuta acciones, no modifica registros y no debe recibir contraseñas, tokens, documentos personales ni datos operativos reales.

Para localizar rápidamente el documento correcto se debe consultar primero [el índice funcional](indice.md).
