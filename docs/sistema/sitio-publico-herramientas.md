# Sitio público, noticias y herramientas

## Editar contadores del sitio público

1. Abrí [Contadores web](/web-admin/contadores).
2. Actualizá cifras generales o series mensuales.
3. Revisá cuidadosamente los valores.
4. Guardá. El sistema regenera la configuración pública y registra auditoría.

## Editar textos

1. Abrí [Textos web](/web-admin/textos).
2. Localizá el bloque por página o sección.
3. Modificá el contenido.
4. Usá la vista previa.
5. Guardá cuando el resultado sea correcto.

## Crear una noticia

1. Abrí [Noticias](/noticias).
2. Pulsá **Nueva noticia**.
3. Completá título, bajada, cuerpo y fecha.
4. Elegí borrador o publicada.
5. Cargá imágenes y seleccioná miniatura.
6. Guardá y revisá la vista pública.

Al editar se pueden agregar imágenes, cambiar la miniatura o marcar imágenes para eliminación.

## Historia, tecnología, galería y dependencias web

1. Abrí el módulo correspondiente desde **Administrar Web**.
2. Creá, editá, ordená o eliminá elementos según tus permisos.
3. Adjuntá imágenes cuando corresponda.
4. Usá la vista previa general.
5. Guardá. Los archivos de datos públicos se regeneran automáticamente.

## Calcular hash SHA-256

1. Abrí [Herramienta de hash](/herramientas/hash-archivo).
2. Seleccioná o arrastrá el archivo.
3. Pulsá **Calcular SHA-256**.
4. Copiá el hash o el reporte resumido.
5. Revisá el historial si necesitás confirmar un cálculo anterior.

El contenido del archivo se procesa localmente en el navegador en el flujo principal; el historial conserva metadatos y el resultado, no el archivo original.

## Plano del edificio

1. Abrí [Plano 911](/plano-edificio).
2. Activá capas y filtrá por tipo, oficina, piso o estado.
3. Seleccioná un dispositivo para consultar su ficha.
4. Con permiso de edición, creá o actualizá nombre, tipo, oficina, piso y datos técnicos.
5. Con permiso de posición, arrastrá el dispositivo y soltalo en la ubicación correcta.
6. Exportá el listado cuando esté habilitado.

La información de acceso asociada a dispositivos requiere un permiso específico y no debe compartirse con el asistente.
