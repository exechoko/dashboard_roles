# Entregas y patrimonio

## Entregar equipos de mano

1. Abrí [Entregas de equipos](/entrega-equipos) y pulsá **Nueva Entrega**.
2. Completá fecha, hora, dependencia, personal, legajos y motivo.
3. Buscá y seleccioná al menos un equipo portátil disponible.
4. Indicá segunda batería, cunas y transformadores cuando correspondan.
5. Adjuntá imágenes o documento de respaldo.
6. Guardá. Los equipos quedan marcados como entregados.
7. Generá el acta Word desde el detalle.

## Devolver equipos de mano

1. Abrí el detalle de la entrega.
2. Pulsá **Devolver**.
3. Seleccioná únicamente los equipos pendientes de esa entrega.
4. Completá fecha, hora, persona, legajo y observaciones.
5. Adjuntá respaldo si corresponde.
6. Guardá. La devolución puede ser parcial o total.

## Entregar bodycams

1. Abrí [Entregas de bodycams](/entrega-bodycams).
2. Creá una entrega normal o un recambio tecnológico.
3. Completá datos del acta, personal y motivo.
4. Seleccioná las bodycams habilitadas para ese tipo de entrega.
5. Adjuntá respaldo y guardá.
6. Generá el acta.

Las entregas normales admiten devolución. Los recambios tecnológicos no requieren devolución desde este flujo.

## Entrega de combustible

1. Abrí [Entregas de combustible](/entrega-combustible).
2. Completá fecha, hora, ticket, empresa, receptor y personal que entrega.
3. Informá litros, bidones, litros por bidón y tipo de combustible.
4. Agregá remito, estación y observaciones cuando correspondan.
5. Guardá y generá el acta.
6. Desde el detalle podés cargar posteriormente el acta firmada.

## Panel de patrimonio

1. Abrí [Panel de patrimonio](/patrimonio/dashboard).
2. Consultá los totales por estado y destino.
3. Usá los accesos directos a cargos y bienes.

## Cargos patrimoniales

1. Abrí [Cargos patrimoniales](/patrimonio/cargos).
2. Filtrá por estado, dependencia, texto o fechas.
3. Abrí un cargo para revisar equipos, historial, firma y acta.
4. En cargos pendientes, agregá o quitá equipos disponibles según autorización.
5. Generá el acta.
6. Para firmar, completá datos del firmante y adjuntá el acta si corresponde.
7. Para rechazar, ingresá obligatoriamente el motivo u observación.

## Alta de un bien patrimonial

1. Abrí [Bienes patrimoniales](/patrimonio/bienes).
2. Pulsá **Nuevo Bien**.
3. Elegí el tipo de bien.
4. Completá destino, ubicación, descripción, identificadores y fecha de alta.
5. Si el tipo se vincula con otro inventario, seleccioná un elemento disponible.
6. Adjuntá documentación o imágenes y guardá.

## Trasladar o dar de baja un bien

Para traslado:

1. Abrí el bien activo y seleccioná **Traslado**.
2. Elegí nuevo destino y ubicación.
3. Agregá observaciones y respaldo.
4. Confirmá.

Para baja:

1. Abrí el bien y seleccioná **Baja**.
2. Elegí desuso, transferencia o rotura.
3. Si es transferencia, indicá el destino.
4. Completá observaciones, adjuntá respaldo y confirmá.

La baja cambia el estado patrimonial del bien y queda asentada con el usuario que la realizó. Hay que verificar que sea el registro correcto antes de confirmar.

## Tipos de bien

1. Abrí [Tipos de bien](/patrimonio/tipos-bien).
2. Consultá o cargá los tipos disponibles.

Cada tipo define qué campos pide el alta y si el bien se vincula con otro inventario del sistema, por ejemplo con un equipo o una cámara.
